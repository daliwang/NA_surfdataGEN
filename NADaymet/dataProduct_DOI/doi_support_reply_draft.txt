Response to your review items

1. Variables listed in the README but missing from the previous NetCDF

   • pft_percentage, urban_percentage, lake_percentage — These diagnostic fields are now included in c260603.nc. They report the vegetation, urban, and lake components as a percentage of the active land-unit pixel total (pft + urban + lake + glacier) and are provided for quality assurance alongside the ELM surfdata fields (PCT_NATVEG, PCT_URBAN, PCT_LAKE).

   • glacier_percentage — Also added in c260603.nc (was omitted from the earlier README list; it is now documented).

   • lake_fraction — This name was incorrect in the README variable list. The product does not define a variable called lake_fraction. Lake coverage is given by PCT_LAKE (ELM surfdata fraction) and lake_percentage (diagnostic). Partial-cell land occupancy is given by land_fraction. We have removed any reference to lake_fraction from veg_landunit_meta_data.md and clarified the intended variables.

2. Variables present in the NetCDF but missing from the README variable list

   • gridID — Now listed in veg_landunit_meta_data.md (template grid cell identifier from the surfdata shell).

   • glacier_count — Now listed in veg_landunit_meta_data.md (30 m pixel count for NALCMS class 19 / glacier).

3. Consistency check

   We verified that all 23 documented names in veg_landunit_meta_data.md (coordinates y, x, index natpft, and 20 data fields) are present in c260603.nc with matching dimensions. No extra data fields appear in the file beyond those listed in the metadata.
